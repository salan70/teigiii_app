# 計画の実行

## 概要

計画を読み込み、批判的にレビューし、すべてのタスクを実行し、完了を報告します。

**開始時に宣言:** 「wf-04-executing-plans スキルを使ってこの計画を実装します。」

**注意:** サブエージェントにアクセスできる環境の方が Superpowers はより効果的に動作することをユーザーに伝えてください。サブエージェントをサポートするプラットフォーム（Claude Code や Codex など）で実行すると、成果物の品質が大幅に向上します。サブエージェントが利用可能な場合は、このスキルの代わりに superpowers:wf-04-subagent-driven-development を使用してください。

## プロセス

### Step 1: 計画の読み込みとレビュー
1. 計画ファイルを読む
2. 批判的にレビュー — 計画に対する疑問や懸念を特定
3. 懸念がある場合: 開始前にユーザーに相談
4. 懸念がない場合: TodoWrite を作成して進行

### Step 2: タスクの実行

各タスクについて:
1. in_progress にマーク
2. 各ステップを正確に実行（計画には一口サイズのステップがある）
3. 指定された検証を実行
4. completed にマーク

### Step 3: 開発の完了

すべてのタスクが完了・検証された後:
- 宣言: 「wf-07-finishing-a-development-branch スキルを使ってこの作業を完了します。」
- **必須サブスキル:** superpowers:wf-07-finishing-a-development-branch を使用
- そのスキルに従ってテスト検証、オプション提示、選択の実行を行う

## 中断して助けを求めるタイミング

**以下の場合は即座に実行を停止:**
- ブロッカーに遭遇（依存関係の欠落、テスト失敗、指示が不明確）
- 計画に致命的な欠陥があり開始できない
- 指示を理解できない
- 検証が繰り返し失敗する

**推測せず、確認を求めてください。**

## 前のステップに戻るタイミング

**レビュー (Step 1) に戻る場合:**
- ユーザーがフィードバックに基づいて計画を更新した
- 根本的なアプローチの再考が必要

**ブロッカーを無理に突破しない** — 立ち止まって確認する。

## 注意事項
- まず計画を批判的にレビュー
- 計画のステップを正確に実行
- 検証をスキップしない
- 計画が参照するスキルを使う
- ブロックされたら推測せず止まる
- ユーザーの明示的な同意なしに main/master ブランチで実装を開始しない

## 連携

**必須のワークフロースキル:**
- **superpowers:wf-02-using-git-worktrees** — 必須: 開始前に隔離されたワークスペースを構築
- **superpowers:wf-03-writing-plans** — このスキルが実行する計画を作成
- **superpowers:wf-07-finishing-a-development-branch** — すべてのタスク後に開発を完了
