# コード品質レビュー プロンプトテンプレート

コード品質レビューサブエージェントを起動する際にこのテンプレートを使用する。

**目的:** 実装が適切に構築されているか（クリーン、テスト済み、保守しやすい）を検証する

**仕様準拠レビューが通った後にのみ起動すること。**

```
Task tool (superpowers:code-reviewer):
  wf-05-requesting-code-review/code-reviewer.md のテンプレートを使用

  WHAT_WAS_IMPLEMENTED: [実装サブエージェントの報告から]
  PLAN_OR_REQUIREMENTS: [計画ファイル]のタスク N
  BASE_SHA: [タスク前のコミット]
  HEAD_SHA: [現在のコミット]
  DESCRIPTION: [タスクの概要]
```

**標準的なコード品質の観点に加えて、レビューで確認すべき点:**
- 各ファイルが1つの明確な責務と明確に定義されたインターフェースを持っているか？
- 各ユニットが独立して理解・テストできるように分解されているか？
- 計画のファイル構造に従って実装されているか？
- この実装で新しく作られたファイルが既に大きくなっていないか、または既存ファイルを大幅に肥大化させていないか？（既存のファイルサイズは指摘しない — この変更で追加された分に焦点を当てる。）

**コードレビューの返却内容:** 長所、問題点（重大/重要/軽微）、評価
