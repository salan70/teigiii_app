# 仕様準拠レビュー プロンプトテンプレート

仕様準拠レビューサブエージェントを起動する際にこのテンプレートを使用する。

**目的:** 実装サブエージェントが要求されたものを過不足なく作ったことを検証する

```
Task tool (general-purpose):
  description: "タスク N の仕様準拠をレビュー"
  prompt: |
    あなたは実装がその仕様に合致しているかをレビューします。

    ## 要求された内容

    [タスク要件の全文]

    ## 実装サブエージェントが作ったと主張する内容

    [実装サブエージェントの報告から]

    ## 重要: 報告を信用しないこと

    実装サブエージェントは疑わしいほど早く完了しました。報告は不完全、
    不正確、または楽観的な可能性があります。すべてを独自に検証する必要があります。

    **してはいけないこと:**
    - 実装内容について相手の言葉を鵜呑みにする
    - 完全性の主張を信用する
    - 要件の解釈を受け入れる

    **すべきこと:**
    - 実際に書かれたコードを読む
    - 実際の実装と要件を行ごとに比較する
    - 実装したと主張しているが欠けている部分を確認する
    - 言及していない追加機能を探す

    ## あなたの仕事

    実装コードを読んで以下を検証する:

    **要件の不足:**
    - 要求されたすべてを実装したか？
    - スキップや見落としのある要件はないか？
    - 動作すると主張しているが実際には実装していない部分はないか？

    **余分・不要な作業:**
    - 要求されていないものを作っていないか？
    - 過剰設計や不要な機能追加をしていないか？
    - 仕様にない「あると便利」を追加していないか？

    **誤解:**
    - 要件を意図と異なる解釈をしていないか？
    - 間違った問題を解決していないか？
    - 正しい機能を間違った方法で実装していないか？

    **報告ではなくコードを読んで検証すること。**

    報告:
    - ✅ 仕様準拠（コード検査後にすべて合致した場合）
    - ❌ 問題あり: [不足している点や余分な点を、ファイル名:行番号の参照付きで具体的にリストアップ]
```
