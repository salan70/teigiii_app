# CLAUDE.md テンプレート

## 原則

- **簡潔**: 1 行に 1 コンセプト。量より密度。
- **実行可能**: コマンドはコピー＆ペーストで実行可能。
- **プロジェクト固有**: このプロジェクトに固有の情報であり、一般的なアドバイスではない。
- **最新**: コードベースの実態を反映している。

## 推奨セクション

すべてのセクションが必要なわけではない。プロジェクトに関連するものだけを選択する。

### コマンド

```markdown
## コマンド

| コマンド | 説明 |
|---------|------|
| `<install>` | 依存関係のインストール |
| `<dev>` | 開発サーバーの起動 |
| `<build>` | プロダクションビルド |
| `<test>` | テストの実行 |
| `<lint>` | Lint / Format |
```

### アーキテクチャ

```markdown
## アーキテクチャ

```
<root>/
  <dir>/    # <用途>
  <dir>/    # <用途>
```
```

### 主要ファイル

```markdown
## 主要ファイル

- `<パス>` — <用途>
- `<パス>` — <用途>
```

### コードスタイル

```markdown
## コードスタイル

- <規約>
- <代替案よりこのアプローチを選ぶ理由>
```

### 環境

```markdown

- `<変数名>` — <用途>

```

### テスト

```markdown
## テスト

- `<テストコマンド>` — <スコープ>

```

### 注意点

```markdown

- <問題を引き起こす非自明な事項>
- <順序依存や前提条件>
- <よくあるミス>
```
