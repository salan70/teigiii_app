## 1. 新しいツール/コマンド/MCP

- [ ] このセッションで初めて使用したツールやコマンドはあるか？

**提案先**: `CLAUDE.md`（クイックリファレンス）、`settings.json`（権限）

## 2. 繰り返し発生した摩擦

- [ ] 同じ種類のエラーを複数回修正したか？

- [ ] 曖昧な手順による手戻りが発生したか？
- [ ] 予期しない出力が繰り返されたか？

**提案先**: `SKILL.md`（手順の明確化）、`AGENTS.md`（ルール追加）

**提案先**: `CLAUDE.md`（プロジェクト固有ルール）、`AGENTS.md`

## 4. スキルのギャップ

- [ ] 適切なスキルがなく手動で行ったタスクはあるか？
