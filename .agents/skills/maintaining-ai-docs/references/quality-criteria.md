# 品質基準

AI ドキュメント（CLAUDE.md / AGENTS.md / SKILL.md）を 6 基準、100 点満点で評価する。

## 採点基準

### 1. コマンド＆ワークフロー（20 点）

| スコア | 基準 |
|--------|------|
| 20 | 必須コマンド（build / test / lint / deploy）がコンテキスト付きで網羅されている |
| 15 | ほとんどのコマンドがあるが、一部コンテキストが不足 |
| 10 | 基本コマンドのみ、ワークフローの記述なし |
| 5 | コマンドがわずかしかない |
| 0 | コマンドの記述なし |

### 2. 構造の明確さ（20 点）

| スコア | 基準 |
|--------|------|
| 20 | ディレクトリ構成、モジュール間の関係、エントリポイントが明確 |
| 15 | 概要は良好だが、詳細にわずかな不足 |
| 10 | ディレクトリの一覧のみ |
| 5 | 曖昧または不完全 |
| 0 | 構造に関する情報なし |

### 3. 非自明なパターン（15 点）

| スコア | 基準 |
|--------|------|
| 15 | 既知の落とし穴、回避策、エッジケース、「なぜこの方法か」が記述されている |
| 10 | 一部のパターンが記述されている |
| 5 | 最小限の記述 |
| 0 | 記述なし |

### 4. 簡潔さ（15 点）

| スコア | 基準 |
|--------|------|
| 15 | すべての行に価値がある。冗長、重複、自明な情報がない |
| 10 | 概ね簡潔だが、一部冗長 |
| 5 | 散在する冗長なセクション |
| 0 | 大部分がフィラーまたはコードから自明な情報 |

### 5. 鮮度（15 点）

| スコア | 基準 |
|--------|------|
| 15 | コマンドが実行可能、ファイル参照が正確、技術スタックが現状を反映 |
| 10 | 概ね最新だが、わずかに古い部分あり |
| 5 | 複数の古い参照 |
| 0 | 著しく古い |

### 6. 実行可能性（15 点）

| スコア | 基準 |
|--------|------|
| 15 | コマンドがコピー＆ペーストで実行可能、手順が具体的、パスが存在する |
| 10 | 概ね実行可能 |
| 5 | 曖昧な指示が混在 |
| 0 | 抽象的または理論的 |

## グレード

| グレード | スコア | 説明 |
|----------|--------|------|
| A | 90-100 | 包括的、最新、実行可能 |
| B | 70-89 | 良好なカバレッジ、軽微な不足 |
| C | 50-69 | 基本情報あり、主要セクション欠落 |
| D | 30-49 | 内容が乏しいか古い |
| F | 0-29 | 欠落または著しく古い |

## 評価手順

1. 対象ファイルを通読する。
2. コードベースと照合する:
   - 記載されたコマンドは実行可能か？
   - 参照されたファイルは存在するか？
   - 構造の記述は実態と一致しているか？
3. 各基準を採点する。
4. 合計を算出し、グレードを付与する。
5. 具体的な問題点を列挙する。
6. 改善案を提案する。

## レッドフラグ

- 実行不能なコマンド（パスの誤り、依存関係の欠落）
- 削除されたファイルやディレクトリへの参照
- カスタマイズされていないテンプレートコンテンツ（コピー＆ペーストのデフォルト）
- プロジェクトに固有でない一般的なアドバイス
- 未解決の TODO 項目
- 複数ファイルにわたる重複情報

## AGENTS.md と SKILL.md の拡張基準

CLAUDE.md 以外のファイルを評価する際は、以下の追加ポイントも確認する:

### AGENTS.md

- 全エージェント共通ルールは網羅されているか？
- 検証コマンドとコミット規約は実行可能な形式か？
- 完了報告フォーマットは定義されているか？

### SKILL.md

- `description` のトリガーフレーズは十分か（ユーザーの自然な表現をカバーしているか）？
- ワークフローは How レベルまで具体的か（手順、コマンド、例外）？
- SKILL.md 本文と `references/` の分割は適切か（本文が肥大化していないか）？
