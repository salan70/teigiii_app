# ナビゲーション骨格

## 目的

issue #187 の最上位 3 タブと共通ヘッダーを構築し、辞書型 UI の画面責務を固定する。

## 実行手順

1. router と BasePage の期待動作を Widget test で先に定義する
2. 下部ナビゲーションを「あなたの辞書／みんなの辞書／タイムライン」の順へ変更する
3. cold start は「あなたの辞書」、バックグラウンド復帰は現在タブ維持とする
4. タブごとの navigation stack と再タップ時の root／先頭復帰を実装する
5. 共通検索と、あなたの辞書専用アバターのヘッダー導線を実装する
6. Material 2、既存 ColorScheme、LINESeedJP を維持し、誤った M3 移行コメントを修正する
7. router 生成、analyze、関連 test、DocBridge を実行する

## 完了条件

- 3 タブの順序、ラベル、起動画面が仕様どおり
- タブごとの stack と再タップ動作が Widget test で固定されている
- 共通検索とアバター導線が後続画面を接続できる
- Material 3 へ移行していない
- 単独コミットで検証が通る
