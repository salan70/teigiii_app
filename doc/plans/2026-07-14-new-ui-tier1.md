# 新 UI Tier 1（初期リリース）統括プラン

> 注記: ディレクトリ再編に伴いパス表記を現行構成へ更新した（#230）。

## 目的

`doc/specs/new-ui-information-architecture.md` の Tier 1 スコープを、辞書型 UI の初期リリースとして実装する。issue #187（Cloudflare 移行 6/6）の実行計画にあたる。

本プランは統括用であり、各対応事項に着手する際は画面・機能単位の詳細プランを `doc/plans/` に別途作成する。

## 前提

- フェーズ 2〜5（#183〜#186）が完了し、旧 UI が D1/R2 バックエンドで安定稼働していること
- スキーマ（#183）は本プランのスコープ全体をカバー済みであること（Tier 2 は含めない）

## スコープ（Tier 1）

情報設計 §0 の Tier 1 に準拠する。

- 3 タブナビゲーション（あなたの辞書・みんなの辞書・タイムライン）。起動画面は「あなたの辞書」固定
- 複数定義モデル（同一ユーザー・同一言葉に複数投稿）
- 公開 / 非公開（現行パリティ）
- 下書き（サーバー保存・離脱/バックグラウンド時自動保存・同一言葉に複数可）
- 保存した言葉
- 言葉ページ（あなたの定義 / みんなの定義。みんなの定義は他者のみ）
- 定義詳細画面
- 定義の編集期限 1 時間・確定後の言葉変更不可
- グローバル検索（言葉・ユーザーの 2 タブ）
- みんなの辞書（読み順・絞り込み 3 種・言葉登録・登録者非表示）
- タイムライン（見つける = 公開定義 + 言葉登録の完全新着 / フォロー中 = 公開定義のみ）
- リアクション: いいね 1 種（現行パリティ）
- フォロー / ミュート（現行パリティ）
- 言葉の作成者修正（1 時間以内・他ユーザー操作なし）
- 通報（現行相当の導線で代替）
- オンボーディング 1 画面 + 空状態の専用設計
- 削除（論理削除 30 日）

## 実行手順

1. 着手順序の目安（各ステップ着手時に詳細プランを作成する）
   1. ナビゲーション骨格（3 タブ + 起動画面 + ヘッダー）
   2. 言葉ページ（中心画面。あなたの定義 / みんなの定義 / 主要アクション）
   3. 定義の作成・編集フロー（下書き・自動保存・編集期限・状態遷移）
   4. あなたの辞書（概要・定義済み一覧・下書き一覧・保存した言葉）
   5. みんなの辞書（読み順一覧・絞り込み・言葉登録・作成者修正）
   6. タイムライン（見つける / フォロー中）
   7. グローバル検索・定義詳細
   8. オンボーディング・空状態・仕上げ
2. 各ステップは画面単位で段階的にリリース可能な形を保つ（big-bang にしない）
3. 完了した詳細プランは `doc/plans/done/` へ移動する

## 完了条件

- Tier 1 スコープの全機能がリリースされている
- 現行機能のパリティ（公開/非公開・いいね・フォロー・ミュート・通報・プロフィール）が失われていない
- 情報設計ドキュメントと実装の乖離がない（乖離が生じた場合はドキュメント側を更新して記録している）
- Tier 2 の統括プラン（`2026-07-14-new-ui-tier2.md`）へ引き継ぐ準備ができている
