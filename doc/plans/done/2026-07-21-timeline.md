# タイムライン

## 目的

完全新着の「見つける」と、フォロー対象の公開定義だけを扱う「フォロー中」を提供する。

## 実行手順

1. discover union と following pagination の domain/repository test を固定する
2. 「見つける」で公開定義と言葉登録を混在表示する
3. 言葉登録者を表示せず、言葉ページへ遷移する
4. 「フォロー中」で公開定義だけを表示し、既存の follow/mute 挙動を維持する
5. 最後に開いたタブを端末内へ保存し、初回だけ「見つける」にする
6. 両タブへ `定義を書く` の拡張 FAB を置く
7. loading、empty、data、error、refresh、pagination を Widget test する
8. analyze、関連 test、DocBridge を実行する

## 完了条件

- 集約・スコアリングなしの完全新着順を維持する
- フォロー中へ自分・非公開・Draft・言葉登録が混ざらない
- 両タブから同じ定義作成画面へ遷移できる
- 単独コミットで検証が通る
