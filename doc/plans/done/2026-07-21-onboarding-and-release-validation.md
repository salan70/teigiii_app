# オンボーディング・空状態・リリース検証

## 目的

初回導線、全画面状態、iOS 実画面、回帰テストを仕上げ、Tier 1 全体を一般ユーザーへ出せる状態にする。

## 実行手順

1. 初回案内を 1 画面へ整理し、規約・プライバシーポリシー同意を維持する
2. 最初の定義作成時に公開／非公開・Draft を簡潔に説明する
3. 全主要画面の loading、empty、error 文言と再試行を横断確認する
4. light／dark、文字拡大、キーボード、戻る操作を iOS Widget test と実画面で確認する
5. backend/mobile format、analyze、test、OpenAPI freshness、DocBridge を実行する
6. iOS シミュレータで作成、Draft、自動保存、確定、編集、削除、検索、フォロー、ミュート、通報導線を確認する
7. 主要画面の確認画像を PR に掲載する
8. セルフレビューで仕様・差分・生成物・旧画面の残骸を確認する
9. 8 つの詳細 plan を `doc/plans/done/` へ移動する

## 完了条件

- Tier 1 の仕様・実装・テストに乖離がない
- iOS の主要操作を実画面で確認している
- Android のビルド・実画面・配信を完了条件に含めていない
- すべての required CI が成功し、未解決レビュー指摘がない
- Draft PR を Ready にできる
