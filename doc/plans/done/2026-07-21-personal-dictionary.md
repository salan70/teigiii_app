# あなたの辞書

## 目的

自分と言葉との関係を、定義済みの言葉、Draft、保存した言葉、最近の定義として管理できる起動画面を提供する。

## 実行手順

1. overview と一覧 repository の期待 DTO・pagination を test で固定する
2. overview API の Draft 集計を専用テーブルへ切り替える
3. 概要、件数、最近の確定済み定義、`定義を書く` FAB を実装する
4. 定義済みの言葉を言葉単位・読み順・公開／非公開件数付きで表示する
5. Draft を更新日時降順・部分入力対応のラベルで表示し、再開／削除へ接続する
6. 保存した言葉を保存日時降順・定義済み表示付きで実装する
7. 専用 empty 状態から一画面の定義作成へ遷移する
8. loading、empty、data、error、pagination を Widget test する
9. analyze、関連 test、DocBridge を実行する

## 完了条件

- cold start 後の中心画面として必要な管理先へ遷移できる
- Draft と確定済み定義の件数・一覧が混同されない
- empty 状態が事前検索を要求せず最初の定義作成へ導く
- 単独コミットで検証が通る
