# みんなの辞書

## 目的

共有言葉を読み順で連続閲覧し、状態絞り込み、画面内検索、明示的な言葉登録を 1 画面で完結させる。

## 実行手順

1. filter、q、cursor の repository test を追加する
2. 読み順の単一連続リストと読み見出しを実装する
3. `すべて／定義あり／定義なし` 変更時に cursor を破棄して再取得する
4. 300 ms debounce の画面内検索を test-first で実装する
5. 五十音中間ページと旧インデックス依存を削除する
6. 重複候補を提示する言葉登録画面を実装する
7. 登録後の `続けて定義を書く／完了` を実装する
8. loading、empty、data、error、pagination を Widget test する
9. analyze、関連 test、DocBridge を実行する

## 完了条件

- 読み順の連続閲覧と見出し表示が仕様どおり
- filter／検索変更後に古い pagination 状態が混ざらない
- 重複語を誤登録せず、既存語または新規登録後の導線が成立する
- 単独コミットで検証が通る
