# #315: dart_style 3.x への依存更新（案 A）

## 目的

build_runner 系が引き込む `dart_style` を 3.x に揃え、SDK の `dart format` とのスタイル往復を根本解消する。

## 方針

- Riverpod 3 / Freezed 3 には上げない（Dart 3.11.5 / Flutter 3.41.8 上の最小セット）
- `auto_route` 7 → 9.3 は `dart_style` 3 到達に必須のため含める
- PR #321（SDK format 正の暫定）はマージせずクローズ済み。本 PR を #315 の本対応とする

## 実行手順

1. `pubspec.yaml` を light path の制約に更新し `flutter pub get`
2. `AppRouter` を `RootStackRouter` 継承に変更、`popRoute` → `maybePop` 等を直す
3. `just mobile-generate` で生成物を作り直し、`dart_style` が 3.x であることを lock で確認
4. `just format` → clean `mobile-generate` → `just format` で差分ゼロを確認
5. `just mobile-analyze` / `just mobile-test` を通す
6. plan を done へ移し `closes #315` の PR を出す

## 完了条件

- `pubspec.lock` の `dart_style` が 3.x
- clean な状態で format → mobile-generate → format の往復で差分が出ない
- analyze / test が通る
