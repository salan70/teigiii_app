# 言葉ページ

## 目的

言葉を最上位オブジェクトとして、自分の定義・Draft・他者の定義・主要操作を 1 画面に集約する。

## 実行手順

1. API DTO と既存 repository が `scope=mine/others`、sort、保存状態を満たすか test で固定する
2. 言葉ヘッダー、保存、定義作成、通報／修正メニューを実装する
3. 自分の確定済み定義を先頭に 3 件表示し、全件一覧へ接続する
4. 対象 `word_id` の Draft セクションを後続 Draft API へ接続可能な境界で用意する
5. 他者の公開定義だけを新着順／リアクション順で表示する
6. loading、empty、data、error、追加取得失敗を Widget test する
7. analyze、関連 test、DocBridge を実行する

## 完了条件

- 自分と他者の定義が重複表示されない
- 言葉ページ起点の作成では言葉・よみが固定される
- 保存／保存解除と sort が仕様どおり
- 単独コミットで検証が通る
