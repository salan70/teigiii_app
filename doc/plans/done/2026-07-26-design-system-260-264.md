# デザインシステム基盤の実装（#260〜#264）

Issue: #258（親） / #260 #261 #262 #263 #264
仕様の正本: `doc/specs/mobile-app-design-system.md`（#259 で確定）

## 目的

#259 で確定した仕様に基づき、`Ds*` トークン・コンポーネント・Widgetbook・検証・正本ドキュメント・
パイロット移行までを 1 PR で実装し、既存の見た目を変えずに UI の一貫性と AI 実装再現性を確立する。

## grilling で確定した方針

| 論点 | 決定 |
|---|---|
| PR 分割 | #260〜#264 を **1 PR**。コミットは機能単位で細かく分ける |
| Widgetbook 配置 | `mobile_app/widgetbook/`（lib 外）+ `widgetbook` は dev_dependencies |
| use case 登録 | **手書きツリー**。widgetbook_generator は使わない（build_runner の sources 拡張を避ける） |
| golden | **ローカル移行検証専用。CI 対象外**。`@Tags(['golden'])` で分離し、CI は `--exclude-tags golden` |
| golden 範囲 | Ds コンポーネント + パイロット 2 画面の主要状態（移行前 baseline をローカルで撮る） |
| a11y 検査 | **Ds コンポーネントのみ** CI 必須（tapTarget / labeled / textContrast） |
| 違反検出 | **analyzer をライブラリ利用した Dart ツール** `tool/ds_check.dart`（custom_lint plugin は作らない） |
| baseline | **ファイル × ルールの件数** JSON |
| token API | **ハイブリッド**。spacing/radius/size/elevation/opacity は `static const`、色/文字は ThemeExtension + context extension |
| 既存テーマ | `util/constant/{theme_data,color_scheme,text_theme}.dart` は design_system へ移設して削除（参照は 2 箇所のみ） |
| 既存 common_widget | 実体を design_system へ移設し、旧パスは `@Deprecated` typedef で残す（削除条件と追跡 Issue 付き） |
| DsTextField | **初期セットに追加**（パイロットの入力系が `TextFormField` 6 箇所） |
| DocBridge | トークン各節 × トークンクラス、初期セット節 × 各 Ds コンポーネント（約 18 本） |
| 仕様逸脱の反映 | 仕様 doc を先行コミットで更新 + `gh issue edit` で #262 / #258 を更新 + golden 常設化は別 Issue へ退避 |
| 実行体制 | 主線は逐次。`ds_check` 系と skill 作成の 2 本のみ subagent 並列 |

## 実行手順（コミット単位）

1. `docs:` 仕様を今回の決定に更新（golden ローカル限定 / DsTextField 追加 / deprecated typedef 方針）
   + `gh issue edit 262 258` + golden 常設化の追跡 Issue 作成
2. `feat:` トークン層（`DsSpacing` 〜 `DsOpacity`、`DsColors`、`DsTypography`、context extension）
3. `refactor:` `util/constant/` のテーマを design_system へ移設し `BuildContext` 依存を解消、`main.dart` / `like_widget.dart` を更新、旧ファイル削除
4. `test:` トークンの完全性・light/dark 解決の unit / widget test
5. `feat:` Ds コンポーネント（button 系 → field 系 → list/icon → dialog → feedback）を数コミットに分割。既存 common_widget は実体移設 + `@Deprecated` typedef
6. `test:` コンポーネントの widget test と a11y guideline test
7. `feat:` Widgetbook app と use case、`just mobile-widgetbook` / `mobile-widgetbook-build`
8. `feat:` `tool/ds_check.dart` + baseline + `just mobile-ds-check`（subagent A）
9. `ci:` `check.yml` に ds-check と Widgetbook build を追加。`just mobile-test` は golden を除外
10. `docs:` 正本ドキュメント整備 + DocBridge 双方向リンク
11. `feat:` Claude / Codex の UI 実装 skill（subagent B、`porting-ai-assets-to-codex` を使用）
12. `test:` パイロット 2 画面の移行前 golden をローカル生成
13. `refactor:` `DictionaryEveryonePage` を Ds へ移行
14. `refactor:` `DefinitionPostPage` / `WriteDefinitionBasePage` を Ds へ移行
15. `test:` 移行後 golden 差分の確認、baseline 再生成、仕様への反映
16. plan ファイルを `doc/plans/done/` へ移動
