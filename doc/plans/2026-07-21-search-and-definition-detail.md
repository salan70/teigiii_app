# グローバル検索・定義詳細・公開プロフィール

## 目的

全タブ共通の検索、独立した定義詳細、辞書中心の公開プロフィールと現行パリティの補助導線を完成させる。

## 実行手順

1. 言葉／ユーザー検索の query、tab state、pagination を test-first で実装する
2. 検索確定時だけ API を呼び、タブ間で検索文字列を維持する
3. 定義詳細を言葉、投稿者、本文、公開状態、編集操作、いいね、通報へ接続する
4. 公開プロフィールを言葉単位・読み順の公開辞書へ変更する
5. `いいねした投稿` を自分・他ユーザーのプロフィールから独立一覧へ接続する
6. 補助画面は必要な導線・共通テーマ整合だけ修正する
7. 汎用通報フォーム URL を対象種別／対象 ID／報告者 ID の事前入力へ変更する
8. loading、empty、data、error、主要遷移を Widget test する
9. analyze、関連 test、DocBridge を実行する

## 完了条件

- 検索確定前に API を呼ばず、言葉／ユーザーを同じ query で検索できる
- 定義詳細から言葉・プロフィール・いいね一覧・通報へ遷移できる
- 公開プロフィールは辞書を主表示しつつ、いいねした投稿一覧を維持する
- 単独コミットで検証が通る
